# Notes for Claude Code

Before pushing a change to code (not for typo fixes in the docs), get a second opinion from free models with the private tool repository `Pressimize/second-opinion`: clone it next to this repository (`git clone https://github.com/Pressimize/second-opinion ../second-opinion`) and follow its README. If it cannot be cloned, say so in the PR text and continue without it.

Earlier reviews and the points they settled are in `docs/reviews/`. Read them before raising a point again.
